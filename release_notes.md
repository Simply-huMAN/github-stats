## What's Changed in v0.5.0

MyGitStats has a new homepage, a heatmap G logo, and a consistent design across Card Studio, Compare, and Wrapped.

- **Two card styles.** Minimal shows a compact set of stats and a heatmap. Showcase adds the layered backdrop, profile details, and tier breakdown. Both homepage previews use Site Green.
- **A new default in Card Studio.** Site Green joins the city palettes and tier colors. The G watermark follows the selected palette in the preview and exported PNG. Card links preserve the style and theme.
- **Compare on smaller screens.** Profile cards stay side by side, all six metrics fit without sideways scrolling, and separate share, copy-link, and PNG export controls are available on the result.
- **README examples.** The project README shows both styles and explains how to add a downloaded PNG to a GitHub profile.
